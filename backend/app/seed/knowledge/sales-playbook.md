# Sales Playbook — Device Control

## Messaging principles
Lead with the prospect's own risk context (regulation, hybrid work, removable-media incidents). Only reference technologies or incidents that are verifiably public. Never promise absolute security or guarantees. Always include an opt-out and clear sender identity.

## Decision makers
In organisations above 1,500 employees, the CISO usually owns device-control decisions with the CIO as budget holder. Between 500 and 1,500 employees, the Head of Information Security or IT Director typically leads. Below 500, the IT Manager or Operations Director decides.
